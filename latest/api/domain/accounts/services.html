async revoke_login_method(account_id: str, method_id: str, *, require_remaining: bool) → RevokeLoginMethodStatus[source]#

Remove one of the account’s login methods together with the MFA factor or passkey behind it.

The account stays locked for the transaction, so concurrent revocations cannot each remove a different method and leave the account without any. Every login method counts towards the one that must remain, second factors included, which is the contract of the security library’s login method store.

Returns:

REVOKED, NOT_FOUND when the account has no such method, or FINAL_METHOD when require_remaining is set and the method is the account’s only login method.

async unlink_oauth_account(user_id: UUID, oauth_account_id: UUID, provider: str, *, require_remaining: bool) → UnlinkStatus[source]#

Remove one of the user’s linked provider accounts.

The account stays locked for the transaction, so concurrent unlinks cannot each remove a different link and leave the account without a way to sign in. Login methods are counted before the link is looked up, so on a database without row locks the loser of a race for the same link still reads NOT_FOUND instead of FINAL_METHOD. Only methods that sign the account in on their own count towards the one that must remain, because a TOTP factor cannot replace the link.

Returns:

UNLINKED, NOT_FOUND when the user has no such link, or FINAL_METHOD when require_remaining is set and the link is the only way left to sign in to the account.
